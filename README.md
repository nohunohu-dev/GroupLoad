# グループ負荷ボード（GroupLoad）

チームの仕事を「誰が・いつ・どれくらいの重さで」持っているかを週ごとに見るための Windows アプリです。ここは配布用の置き場で、ソースは置いていません。

## ダウンロード

右の **Releases**（または [最新の版](../../releases/latest)）から `GroupLoad-v<版>-win.zip` をダウンロードしてください。

## 使い方

1. zip を自分の PC のフォルダ（例：`C:\Tools\GroupLoad`）に展開します。インストールも、管理者の権限も要りません。
2. 中の `GroupLoad.exe` を開きます。説明書は同じフォルダの `manual\index.html` です。

Box や共有フォルダ（ネットワーク上）の中に置いたまま起動しないでください。Box の中では、同期中のファイルがロックされて開けなかったり、消えたりします。必ず自分の PC のフォルダに展開してから使ってください。

新しい版に入れ替えるときは、アプリを終了し（トレイのアイコンを右クリックして「終了」）、フォルダの中身を全部入れ替えます。データ（`%APPDATA%\GroupLoad`）はそのまま使えます。
